Second Look

Before a woman with possible heart attack symptoms is sent home from A&E, Second Look checks that the work-up is actually complete. When it is, it stays silent.

How it works

Four checks, run at the moment of discharge

Second Look only runs when the discharge diagnosis is non-cardiac (anxiety, reflux, indigestion…) and the triage note mentions heart-type symptoms. Missing information is never treated as safe: it becomes a question.

  1. 01

    Triage note

    Free text mapped to 13 symptoms, including the ones women report more often: nausea, back or jaw pain, fatigue. Negation is handled, so "no chest pain" is not chest pain.

  2. 02

    Troponin

    Flags a missing test, a single test under 3 h from onset, a rise between tests, or any value above the sex-specific 99th percentile.

  3. 03

    12-lead ECG

    Measures ST deviation in every lead and looks for contiguous-lead patterns: STEMI-level, subtle elevation just below the thresholds, or depression.

  4. 04

    History

    Pre-eclampsia, recent pregnancy (SCAD), early menopause, diabetes, repeat visits. With no record, four bedside questions.

ECG signal processing

  1. Band-pass filter each lead at 0.05–40 Hz (zero-phase Butterworth). The 0.05 Hz corner keeps the ST segment intact.
  2. Detect R peaks in lead II, Pan-Tompkins style: 5–15 Hz band-pass, derivative, squaring, 150 ms moving-window integration, then snap to the largest deflection.
  3. For every beat, measure the signal 100 ms after the R peak against the PR baseline 80 ms before it. Take the median across beats.
  4. Apply sex- and age-specific STEMI thresholds by contiguous lead group (inferior, anterior, lateral), plus a "subtle" band just below them.

Built with

Python (NumPy, SciPy, wfdb) for the signal processing and the rules engine, covered by a pytest suite. This page runs a JavaScript port of the same engine, checked against the Python version on more than 2,000 generated cases on every test run. A Streamlit version of the prototype lives in the same repository.

Limitations

Not a medical device and not for clinical use. Troponin limits are placeholders for one assay. The rules are a prototype of guideline logic, not a validated tool, and symptom reading is keyword-based.
